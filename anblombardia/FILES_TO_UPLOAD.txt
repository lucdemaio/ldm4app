🚀 PROCEDURE DI DEPLOY
================================================================================

PASSO 1: VERIFICA LOCALE
───────────────────────
1. Apri: index_new_2026.html nel browser
2. Verifica: Header, menu, particelle, scroll parallax
3. Test responsive: F12 e ridimensiona browser
4. Controlla: Link funzionanti, immagini caricate

PASSO 2: UPLOAD SU SERVER (Via FTP)
───────────────────────────────────
1. Accedi al pannello hosting (Aruba)
2. Usa FileZilla o client FTP
3. Carica i 3 file critici:
   - index_new_2026.html → /public_html/
   - modern2026.css → /public_html/css/
   - modern2026.js → /public_html/js/
4. Verifica permessi (644 per file)

PASSO 3: BACKUP VECCHIO SITO
───────────────────────────
1. Scarica vecchio index.html
2. Rinomina in: index_backup_2026_03_16.html
3. Salva in locale per sicurezza

PASSO 4: TEST LIVE
──────────────────
1. Naviga a: www.anblombardia.it/index_new_2026.html
2. Verifica: Tutto carica correttamente
3. Testa su mobile
4. Controlla console (F12) per errori

PASSO 5: ATTIVAZIONE
────────────────────
OPZIONE A (Consigliato):
  - Via SSH/FTP rinomina:
    index.html → index_old_backup.html
    index_new_2026.html → index.html
  - Risultato: www.anblombardia.it/ carica nuovo sito

OPZIONE B (Mantenere entrambi):
  - Tienere entrambi i file
  - Vecchio: www.anblombardia.it/index.html
  - Nuovo: www.anblombardia.it/index_new_2026.html

PASSO 6: COMMIT GIT
───────────────────
```
git add index_new_2026.html css/modern2026.css js/modern2026.js
git commit -m "🎉 Modernizzazione 2026 - Nuovo design dinamico"
git push origin main
```
