📚 Come Funziona l'IA?

🧠 Cosa è un Modello AI?

Un modello di intelligenza artificiale è un "cervello digitale" allenato su miliardi di parole. Impara a riconoscere pattern e significati, permettendogli di generare risposte coerenti alle tue domande.

⚙️ Come Lavora?

Quando fai una domanda:

  1. Legge le parole - Converte il testo in numeri che comprende
  2. Applica logica - Usa reti neurali per analizzare il significato
  3. Genera risposta - Predice parola dopo parola, una alla volta
  4. Ritorna il risultato - Ti mostra il testo completo

🎯 Cosa Puoi Fare?

  • ✅ Fai domande - Su qualsiasi argomento
  • ✅ Chiedi traduzioni - In qualsiasi lingua
  • ✅ Scrivi codice - Python, JavaScript, SQL, etc.
  • ✅ Analizza testi - Riassunti, sentiment analysis
  • ✅ Brainstorming - Idee creative, scenari
  • ✅ Impara - Spiegazioni semplici di concetti complessi

🔑 Guida Completa: Come Ottenere la Chiave Groq API

⚡ Perché Groq?

  • Rapidissimo - Risposte in millisecondi
  • Gratis - Tier gratuito generoso (5000 richieste/mese)
  • Affidabile - API stabile e ben documentata
  • Integrato - Funziona con tutti i nostri gestioni

📋 Step-by-Step: Registrazione Groq

1

Apri il sito Groq

Vai a console.groq.com

Clicca questo link per aprire la console Groq → 
https://console.groq.com
2

Crea un account (se non lo hai)

Se non hai un account Groq:

  • Clicca "Sign Up" o "Create Account"
  • Scegli il metodo (Email, Google, GitHub)
  • Completa la verifica email (controlla spam se non arriva)
  • Accedi alla console
3

Accedi alla sezione API Keys

Una volta loggato:

  • Nel menu a sinistra, cerca "API Keys" o "Keys"
  • Oppure vai direttamente a: console.groq.com/keys
4

Crea una nuova API Key

Nella pagina API Keys:

  • Clicca il bottone "+ Create API Key" (di solito blu/verde in alto)
  • Dai un nome descrittivo, ad es: "ldm4app-my-groq-key" o "personal-key"
  • Clicca "Create" o "Generate"
5

Copia la chiave

⚠️ IMPORTANTE:

La nuova API Key sarà visualizzata una sola volta!

👉 Clicca il bottone "Copy" o seleziona il testo intero e copia con Ctrl+C

Se la perdi, dovrai crearne una nuova (è facile, ma non la potrai recuperare)

6

Incolla la chiave su LDM4APP

Torna a questa pagina e:

  • Scorri in basso fino al riquadro "⭐⭐ Groq (consigliato)"
  • Nel campo con label "Groq API Key", incolla la chiave (Ctrl+V)
  • ✅ La chiave è salvata localmente (solo nel tuo browser)
7

Prova l'IA!

Scrivi una domanda nel riquadro "Domanda" e clicca "Chiedi"

✨ Primo test consigliato: 
"Ciao! Dimostrami che sei connesso e veloce 🚀"

Dovresti ricevere una risposta in meno di 1 secondo!

✅ Verifiche e Troubleshooting

  • ❓ La chiave non funziona? → Ricopia dalla console Groq (potrebbe avere spazi extra)
  • ❓ Errore "Invalid API Key"? → Ricrea una nuova key nella console
  • ❓ Status mostra "errore"? → Controlla la console del browser (F12) per dettagli
  • ❓ Vuoi usare il proxy? → Se il server è configurato, la chiave non serve (proxy usa la sua key)

🔒 Sicurezza & Privacy

  • ✅ La tua API key è salvata solo nel tuo browser (localStorage)
  • ✅ Non viene mai inviata a server terzi di LDM4APP
  • ✅ Se usi un dispositivo pubblico, ricordati di cancellarla ({F12 → Application → Storage})
  • ✅ Puoi disabilitare/rigenerare la key dalla console Groq in qualsiasi momento
