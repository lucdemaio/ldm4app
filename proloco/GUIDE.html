💡 Come Usare Ogni Sezione

Dashboard

Pagina di benvenuto con:

  • Statistiche Principali: Eventi totali, volontari attivi, saldo budget
  • Avvisi: Compiti scaduti, budget in deficit, volontari insufficienti
  • Prossimi Eventi: Lista dei 5 prossimi eventi pianificati
  • Compiti Recenti: Ultimi compiti creati con status

Gestione Eventi

Workflow completo per gestire gli eventi:

  1. Click ➕ Nuovo Evento
  2. Compila form: titolo, data, luogo, categoria, budget
  3. Modifica evento: click su un evento e "Modifica"
  4. Elimina evento: click "Elimina" e conferma
  5. Cambia status: pianificato → in corso → completato

Gestione Volontari

Registra e gestisci i tuoi volontari:

  1. Click ➕ Nuovo Volontario
  2. Compila: nome, email, telefono, ruolo, abilità
  3. Seleziona giorni disponibili (es: Lunedì, Mercoledì)
  4. Il sistema traccia automaticamente le ore lavorate
  5. Visualizza statistiche: ore totali, ruoli, abilità

Gestione Budget

Contabilità semplificata:

  1. Click ➕ Nuova Voce
  2. Scegli Tipo: Entrata o Spesa
  3. Seleziona categoria (Catering, Marketing, Materiali, etc)
  4. Sistema calcola automaticamente: Entrate - Spese = Saldo
  5. Statistiche per categoria nella sezione Budget

Gestione Compiti

Task management integrato:

  1. Click ➕ Nuovo Compito
  2. Imposta: titolo, descrizione, priorità, scadenza
  3. Assegna a un volontario specifico
  4. Traccia status: Pending → In Progress → Completed
  5. Avvisi automatici per compiti scaduti

Rapporti e Statistiche

Analisi complete e export dati:

  • Report Completo: Statistiche tutti i moduli
  • Export JSON: Backup completo dati
  • Export CSV: Per fogli di calcolo (Excel)
  • Grafici Visivi: Tutti i dati con visualizzazione
  • Volontari Top: Chi ha lavorato più ore
  • Stato Financial: Budget health (sano, warning, critico)

🔧 Funzioni Avanzate

Personalizzare i Colori

  1. Vai a Impostazioni
  2. Sezione Tema e Colori
  3. Seleziona colore primario (header, pulsanti)
  4. Seleziona colore secondario (accenti)
  5. Click Applica Colori per applicare subito

Esportare i Dati

JSON: Backup completo

  1. Vai a Rapporti
  2. Click 📥 Scarica JSON
  3. Salva file per backup sicuro
  4. Puoi reimportare in Impostazioni → Gestione Dati

CSV: Per Excel e Fogli di Calcolo

  1. Vai a Rapporti
  2. Click 📊 Scarica CSV
  3. Apri con Excel o Google Sheets

📁 Gestione Dati

ℹ️ Dove sono salvati i dati?
I dati sono salvati nel localStorage del tuo browser. Sono completamente privati e offline. Non vengono inviati a nessun server.

Backup Base

  1. Vai a Impostazioni
  2. Click 📥 Esporta Impostazioni
  3. Scarica file JSON con tutti i dati
  4. Conserva in luogo sicuro

Ripristinare da Backup

  1. Vai a Impostazioni
  2. Click 📤 Importa Impostazioni
  3. Seleziona file JSON dal backup
  4. Dati vengono ripristinati automaticamente

Cancellare Tutto

⚠️ Attenzione: Questa azione è irreversibile!
Vai a Impostazioni → Gestione Dati → Ripristina Predefiniti per azzerare tutto.

❓ Domande Frequenti

D: I miei dati sono salvati?

R: Sì! Automaticamente nel localStorage del browser. Non vengono mai inviati a server esterni.

D: Posso usarlo offline?

R: Sì, completamente offline dopo il caricamento iniziale. È una web app offline-first.

D: Come faccio backup?

R: Impostazioni → Gestione Dati → Esporta Impostazioni per scaricare JSON.

D: Posso personalizzare i colori?

R: Sì! Impostazioni → Tema e Colori per cambiare i colori primari e secondari.

D: È gratis?

R: Sì, completamente gratis e open source. Nessun costo, nessun abbonamento.

D: Posso aggiungere più eventi?

R: Illimitati! L'unico limite è lo spazio nel localStorage del browser (solitamente 5-10MB).
