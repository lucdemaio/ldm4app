## 🚀 Come Utilizzare il Sito

### **Visualizzazione Locale**
1. Aprire `index.html` nel browser
2. Navigare tramite menu principale (Home, Chi Siamo, Programma, Galleria, Contatti)
3. Tutti i link sono funzionanti e navigano correttamente tra le pagine

### **Personalizzazione**

#### 1. **Aggiornare i Contatti**
Cercare e sostituire:
- `info@radunobersaglierivivevano2027.it` → con email reale
- `+39 XXXX XXX XXX` → con telefono reale
- Effettuare in: `index.html`, `pages/about.html`, `pages/program.html`, `pages/contact.html`

#### 2. **Aggiungere Foto Aggiuntive**
- Inserire le foto nella cartella `assets/` (o nella root)
- Modificare i percorsi in `pages/gallery.html`

#### 3. **Aggiungere Link Social**
In `pages/contact.html`, aggiornare gli href:
```html
<a href="https://facebook.com/tuoprofilo">Facebook</a>
<a href="https://instagram.com/tuoprofilo">Instagram</a>
```

#### 4. **Personalizzare Colori**
In `css/styles.css`, modificare le variabili CSS:
```css
--primary-color: #c45b3e;  /* Cremisi Bersaglieri */
--secondary-color: #2c3e50;
--accent-color: #27ae60;
```
