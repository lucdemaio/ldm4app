# 🏆 Gestionale Tornei Pro v2.0 - GUIDA ITALIANA

**Il miglior programma GRATUITO per gestire tornei sportivi** ⚡

---

## 🎯 Cos'è?

Un'applicazione web **professionale**, **completamente gratuita** e **open-source** per la gestione di:

- ⚽ Campionati calcio
- 🏀 Tornei basket
- 🏐 Tornei pallavolo
- 🎾 Competizioni tennis
- 🏓 Ping pong
- E tutti gli sport immaginabili!

**PERFETTO PER:**
- Pro Loco locali
- Associazioni Sportive Dilettantistiche (ASD)
- Oratori e parrocchie
- Scuole e centri sportivi
- Palestre e circoli privati
- Chiunque voglia organizzare un torneo

---

## ✨ Cosa Puoi Fare?

### 📋 Gestione Tornei
- Crea tornei illimitati
- Scegli sport e formato (girone, playoff, misto)
- Auto-genera calendario
- Gestisci squadre e giocatori
- Traccia risultati in tempo reale

### 👥 Gestione Giocatori
- Registra tutti i giocatori
- Assegna ruoli (portiere, difensore, etc)
- Numeri maglia
- Traccia presenze e statistiche
- Note mediche (infortuni, squalifiche)

### 📊 Statistiche e Classifiche
- Classifica automatica
- Top scorer
- Top assist
- Statistiche per giocatore
- Grafici e trend
- Export PDF/CSV

### 📱 Accessibilità
- Funziona offline (senza internet!)
- Installabile come app
- Dark Mode / Light Mode
- 5 lingue (IT, EN, ES, FR, DE)
- Responsive mobile/tablet/desktop

## 📖 Guida Rapida

### Crea il tuo primo torneo in 3 minuti

```
1. Clicca "Nuovo Torneo"
   ├─ Nome: "Torneo Calcio Estivo 2026"
   ├─ Sport: Calcio
   ├─ Squadre: 8
   └─ Formato: Girone all'italiana

2. Aggiungi squadre
   ├─ AC Milano
   ├─ Inter
   ├─ Juventus
   └─ ... (altre 5)

3. Aggiungi giocatori
   ├─ Per ogni squadra, aggiungi i tuoi giocatori
   ├─ Assegna ruoli e numeri
   └─ Il sistema traccia automaticamente

4. Genera calendario
   ├─ Clicca "Genera Calendario"
   ├─ Verifica la proposta
   └─ Pubblica quando pronto

5. Inserisci risultati
   ├─ Vai a "Giornate"
   ├─ Clicca partita
   ├─ Inserisci risultato
   └─ Classifica si aggiorna AUTOMATICAMENTE!

6. Visualizza classifica
   ├─ Vai a "Classifiche"
   ├─ Vedi classifica aggiornata
   └─ Esporta PDF per stampare
```

## 🔧 Configurazione Avanzata

### Abilita Cloud Sync (Opzionale)
Se hai un server, puoi sincronizzare nel cloud:

```
1. Admin Panel > Impostazioni
2. Abilita API Cloud
3. Inserisci URL server
4. Inserisci API Key
```

### Cambia Dark Mode
```
Clicca icona 🌙 in alto a destra
→ Tema scuro si attiva immediatamente
```

### Cambia Lingua
```
Clicca icona 🌍 in alto a destra
→ Scegli fra 5 lingue disponibili
```

## 📱 Installa come App

### Android (Chrome)
1. Apri browser Chrome
2. Vai su `index.html`
3. Tap menu (⋮) > "Installa app"
4. Tap "Installa"
✅ App nella home screen!

### iPhone (Safari)
1. Apri browser Safari
2. Vai su `index.html`
3. Tap condivisione (⬆️)
4. Tap "Aggiungi a Home"
✅ App nella home screen!

### Desktop (Windows/Mac)
1. Apri nel browser Chrome o Edge
2. Click address bar
3. Click "Installa" (appare icon)
4. ✅ App desktop installata!

## 🆘 Aiuto & Support

### Problemi Comuni?

**"Dice che storage è pieno"**
```
Admin Panel > Backup > Esporta Completo
Admin Panel > Impostazioni > Resetta Dati
Reimporta backup
```

**"App va lenta"**
```
Pulisci cache: Ctrl+Shift+Del
Oppure esporta dati vecchi
```

**"Dati non sincronizzano"**
```
Controlla internet (deve essere online se abiliti Cloud)
Verifica impostazioni cloud
```
