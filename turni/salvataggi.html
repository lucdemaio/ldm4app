📖 Guida completa al gestionale

Introduzione

Questa guida spiega in dettaglio le funzionalità del gestionale: come salvare e ripristinare backup, esportare report, gestire la Distribuzione vincolante, usare gli strumenti di pulizia dello spazio locale e risolvere i problemi comuni.

Salvataggi (Backups)

  • 💾 Salva backup: salva lo stato corrente dell'app (dipendenti, rotazioni, fasce orarie, distribuzione) nel tuo browser. Consigliato prima delle modifiche importanti.
  • ⬇️ Scarica: scarica un file JSON del backup per conservazione esterna o import in un altro browser.
  • 🔁 Ripristina: carica lo stato del backup nell'app, sovrascrivendo i dati correnti. Attenzione: operazione irreversibile sui dati in memoria.
  • 🗑️ Elimina: rimuove il singolo backup dal browser.
  • 🧹 Cancella tutti: elimina tutti i backup. È consigliato scaricare i backup importanti prima di eseguire questa operazione.
  • Automazione: il sistema può compattare backup pesanti o rimuovere i più vecchi automaticamente in caso di spazio insufficiente (vedi sezione Pulizia spazio).

Esportazioni

  • 💾 Salva Esportazione: esporta la settimana corrente in Excel/PDF/CSV e la salva in localStorage come 'export' utilizzabile offline.
  • Gestione Export: puoi scaricare o eliminare esportazioni salvate nella sezione Esportazioni.

Import

Puoi importare un backup JSON tramite la pagina principale. Se lo spazio locale è insufficiente, l'app cercherà di scaricare automaticamente il file e ti avviserà con istruzioni per ripristinarlo manualmente.

Distribuzione vincolante e Suggerimenti Riequilibrio

  • Distribuzione: imposti quanti operatori servono per ciascuna fascia (es. T1, T2, T3). Il motore tenterà di rispettare questa distribuzione, bilanciando i carichi tra i dipendenti.
  • Suggerimenti riequilibrio: il sistema propone spostamenti suggeriti (candidati) per coprire i deficit. Puoi Mostra candidati, visualizzare una Anteprima della nuova settimana e poi Applica, Ignora o Forza l'applicazione della modifica.
  • Forza: permette di applicare la modifica anche se il motore non può generare la settimana rispettando i vincoli (usare con cautela).
  • Compatibilità: i suggerimenti rispettano i vincoli di riposo minimi (es. 11h) dove possibile; in caso contrario sarà mostrato un avviso per ogni candidato non compatibile.

Motore di generazione

  • Genera Turni: calcola i turni settimanali rispettando vincoli di pausa e distribuzione, considerando le preferenze e le fasce orarie degli utenti.
  • Conteggi assegnati: il motore mantiene e aggiorna _lastAssignedCounts che vengono usati dalla sezione Distribuzione per proporre riequilibri.
  • Stato di salvataggio: il modal dei suggerimenti può attendere che il motore completi il salvataggio; in presenza di ritardi viene mostrato un banner informativo e puoi usare Apri (forza) per vedere i dati diagnostici immediatamente.

Fasce orarie e Rotazioni

  • 💾 Salva Solo Fasce Orarie: salva rapidamente le fasce dei dipendenti senza alterare altri dati.
  • 💾 Salva Solo Rotazione Reparti: salva la rotazione dei reparti separatamente, utile per rollout o test rapidi.

Pulizia spazio e gestione localStorage

  • AutoCleanLocalStorage: rimuove backup/exports vecchi e chiavi non essenziali per liberare spazio. Esegui manualmente con il pulsante "Pulisci spazio" o abilita politiche automatiche dove disponibili.
  • Politiche: per default il sistema conserva keepBackups=3 e keepExports=3, ma è possibile cambiarle via impostazioni future. Quando lo spazio è critico il sistema proverà prima a compattare, poi a eliminare i più vecchi.
  • Fallback: se il salvataggio fallisce per quota, l'app può scaricare automaticamente un backup JSON sul computer e notificarti di liberare spazio.

Debug e strumenti avanzati

  • Log diagnostici: i messaggi di debug sono visibili nella console del browser e aiutano a capire problemi di conteggi, candidati e salvataggi.
  • Distribuzione debug: funzioni disponibili come Distribuzione.debugCandidates e Distribuzione.forceOpen() aiutano a forzare il rendering delle proposte quando il motore non aggiorna i conteggi.

FAQ e Risoluzione Problemi

  • Impossibile salvare (quota): premi Pulisci spazio o scarica manualmente i backup più importanti e riprova. Se il problema persiste, scarica il backup corrente e prova il ripristino in un altro browser o computer.
  • Modal Suggerimenti vuoto: attendi che il motore completi il salvataggio o usa Apri (forza) per vedere i dati diagnostici; controlla la console per messaggi di errore.
  • Ho perso weeklySchedules: se hai scaricato manualmente le weeklySchedules o un backup, ricaricalo tramite Import/Restore per ripristinare le settimane.

Esempi passo-passo (pratici)

1) Salvare un Backup

  1. Vai su Salvataggi nella barra laterale o apri la pagina Salvataggi.
  2. Inserisci un nome facoltativo nel campo Nome backup.
  3. Clicca 💾 Salva backup. Controlla la tabella per verificare che il backup sia stato aggiunto.
  4. Se vuoi conservarlo esternamente, clicca ⬇️ Scarica nella riga del backup per ottenere il file JSON.

2) Ripristinare un Backup

  1. Nella tabella dei backup clicca 🔁 Ripristina sulla riga desiderata.
  2. Conferma l'operazione quando richiesto (attenzione: sovrascrive i dati in memoria).
  3. Al termine verrai riportato alla home; verifica la tabella principale per i cambiamenti applicati.

3) Creare un'Esportazione dalla copia di un Backup

  1. Clicca il pulsante 📤 Esporta nella riga del backup (o usa il menu Esportazione per salvare la settimana corrente).
  2. Vai alla sezione Esportazione, scarica Excel/PDF da lì.

4) Usare i Suggerimenti Riequilibrio

  1. Definisci la Distribuzione (numero di operatori per fascia) nella UI principale.
  2. Apri la finestra Suggerimenti riequilibrio (Distribuzione).
  3. Usa Mostra candidati per vedere chi può coprire un deficit; clicca Anteprima per vedere la settimana proposta.
  4. Scegli Applica per importare la modifica, oppure Forza se vuoi procedere anche quando il motore non riesce a generare la settimana rispettando tutti i vincoli.

5) Pulizia spazio (quando il browser segnala quota piena)

  1. Usa il pulsante 🧹 Pulisci spazio nella UI principale per avviare AutoCleanLocalStorage.
  2. Il sistema rimuoverà backup/exports più vecchi e tenterà di salvare uno snapshot compatto; controlla la console per i dettagli operativi.
  3. Se necessario, scarica manualmente i backup importanti e poi ripulisci nuovamente.

6) Stampare o salvare la guida in PDF

  1. Clicca 🔖 Stampa / Salva PDF: si aprirà la finestra di stampa del browser; scegli Salva come PDF come destinazione.
  2. Per scaricare direttamente la guida in un popup pronto per la stampa, usa ⬇️ Scarica PDF.
