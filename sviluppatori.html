Giochi Gratuiti per la Community

In questa pagina trovi giochi gratuiti che gli sviluppatori hanno gentilmente concesso per l'utilizzo libero da parte di tutti. Puoi giocarli direttamente online oppure, se sei uno sviluppatore, contattarci per collaborazioni o richieste di integrazione.

Floppy Bird

Un arcade moderno ispirato a Flappy Bird. Supera gli ostacoli, sfida i tuoi amici e scala la classifica!

Gioca a Floppy Bird
Nebez Briefkani
Progetto su GitHub

Floppy Bird è una fedele ricostruzione open source del celebre Flappy Bird, realizzata da Nebez Briefkani per la community.

Controlla un uccellino che deve evitare gli ostacoli.
Il gioco termina se tocchi un ostacolo o il suolo.
Punteggio che aumenta a ogni ostacolo superato.
Grafica minimal, gameplay immediato e reattivo.

Hextris

Un puzzle game frenetico ispirato a Tetris. Ruota l'esagono, impedisci ai blocchi di uscire e crea combo spettacolari!

Gioca a Hextris
Logan Engstrom
Profilo GitHub Progetto su GitHub

Hextris è un gioco open source creato da Logan Engstrom e altri sviluppatori, disponibile gratuitamente per la community.

Ruota l'esagono per gestire i blocchi colorati.
Il gioco termina se i blocchi escono dall'esagono.
Crea combo distruggendo blocchi dello stesso colore.
Gameplay veloce, grafica flat e UI moderna.

HexGL

Un gioco di corse futuristico in HTML5. Guida navi ad alta velocità attraverso circuiti mozzafiato in un ambiente ispirato alla fantascienza.

Gioca a HexGL
Thibaut Despoulain (BKcore)
Profilo GitHub Progetto su GitHub

HexGL è un gioco di corse futuristica in HTML5, open source con licenza MIT.

Corse futuristiche ad alta velocità con controlli reattivi.

Grafica 3D avanzata per un gioco HTML5 classico.

Snake

Il classico Snake in HTML/JS: mangia il cibo per crescere, evita muri e collisioni con te stesso. Gameplay semplice ma coinvolgente.

Gioca a Snake
Aman Singh
Profilo GitHub Progetto su GitHub

Snake-Game-JS è un classico Snake realizzato in HTML/CSS/JavaScript. Apri index.html per giocare — nessuna dipendenza richiesta.

Star Battle

Un frenetico gioco di sparatoria spaziale. Controlla una nave spaziale, raccogli carburante e sconfiggi i nemici nel cosmo.

Gioca a Star Battle
gd4Ark (4Ark)
Profilo GitHub Progetto su GitHub

Star Battle è un gioco di sparatoria spaziale realizzato da gd4Ark con ES6 e Canvas, disponibile gratuitamente per la community.

Controlla una nave spaziale con WASD e spara con Space.
Gestisci il carburante e raccogli rifornimenti per sopravvivere.
Sconfiggi nemici e pianeti per accumulare punti.
Pausa con P, muta audio con M. Gameplay intenso e avvincente.
